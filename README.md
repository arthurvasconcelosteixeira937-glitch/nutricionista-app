# nutricionista-app
Plataforma de consultoria nutricionista com planos de dieta personalizados e acompanhamento de peso e medidas

## Assistente de Retorno (protótipo SaaS para salões de beleza)

Protótipo funcional na pasta [`assistente-retorno/`](assistente-retorno/README.md): reativação de clientes, campanhas com mensagens revisadas, registro de resultados e relatórios. Veja o README da pasta para executar e conhecer as limitações.
